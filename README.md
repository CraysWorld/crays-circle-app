> **Your phone is no longer a device. It's a node.**

Crays Circle is a revolutionary offline-first social networking app that transforms smartphones into smart nodes within a decentralized mesh network. Built for authentic human connections in the Web3 era.

## 🌟 Key Features

- **🌐 Offline-First Mesh Networking** - Connect without internet using proprietary DNC Protocol
- **🧠 Psychology-Driven Matching** - MBTI, Big Five, PI, and Enneagram compatibility
- **🎯 Intention-Based Discovery** - Social, Dating, and Business modes
- **🔒 Privacy-First Decentralization** - Your data stays on your device
- **🏢 Venue-Aware Interactions** - Seamless integration with lifestyle spaces
- **💰 Crypto Payments** - Offline payments and tipping via Crays Coin
- **🎫 NFT Access** - Token-gated VIP experiences and room keys

## 🚀 Getting Started

### Prerequisites

- **iOS**: 14.0+ / **Android**: API level 24+
- Wi-Fi Aware / Bluetooth LE support
- 2GB+ available storage

### Installation

```bash
# Clone the repository
git clone https://github.com/crays-ecosystem/crays-circle.git

# Navigate to project directory
cd crays-circle

# Install dependencies
npm install

# iOS setup
cd ios && pod install && cd ..

# Android setup (if needed)
cd android && ./gradlew clean && cd ..
```
